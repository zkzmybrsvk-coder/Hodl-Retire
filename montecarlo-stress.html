▸ What This Does

The base HODL&Retire tool uses a smooth power-law curve — one deterministic future. Reality is jagged. This runs 1,000 random price paths where the power law is the long-run mean, but each year's actual return is drawn from a volatility distribution around it.

This directly tests sequence-of-returns risk: a 65% crash in year 3 of retirement is catastrophic; the same crash in year 30 barely matters. The single-curve model can't see this — Monte Carlo can.

The verdict is a survival probability: of 1,000 random futures, in how many did your unpledged stack stay positive the whole horizon without collateral running out?

Try the "Pause Borrow On Down Years" toggle. Borrowing during a crash pledges far too many sats at depressed prices — the core failure mode. Skipping the loan in down years (covering that year from outside cash, no BTC touched) is a strong defense. In testing it roughly tripled survival on default settings — but it assumes you actually have that cash reserve set aside.
